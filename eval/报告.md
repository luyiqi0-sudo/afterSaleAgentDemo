# 评测报告

## 数据与入口

[golden_dataset.jsonl](golden_dataset.jsonl) 是默认基线评测入口，共 36 条公开留出案例，覆盖政策、SQL、工具、澄清、确认、安全、恢复和能力缺口。数据与原冻结基线按字节一致；运行器、评分器及探针核验摘要，缺失或修改报 `EVAL_SNAPSHOT_MISMATCH`。

`runner.py` 采集实际 Agent/Mock HTTP 观测，`eval.py` 使用独立 `oracle.py` 评分。产品不读取评测答案。`controlled.py` 提供确定性动作候选，用于机制重复验证，不能代表真实模型语义质量。

## 复现

仓库根目录安装锁定依赖后执行，每次使用新的输出目录：

```powershell
.venv\Scripts\python -m mock.verify_freeze
.venv\Scripts\python -m eval.runner --profile controlled --database-dir database --knowledge-path knowledge --output runtime/golden-run
.venv\Scripts\python -m eval.eval --root data/c004-r01/baseline --contract mvp-agent-v2 --observations runtime/golden-run/observations.json --output runtime/golden-run/evaluation
```

默认读取本目录数据，也可 `--cases-file eval/golden_dataset.jsonl` 显式指定；其他 `--root` 默认读取该包评测，显式文件须与该包 manifest 一致。生成器和原基线内部的副本保留完整数据契约，不作为默认基线评测入口。

`--database-dir database --knowledge-path knowledge` 验证根目录部署文件，省略时使用所选数据包的数据库和政策快照。运行器退出成功只表示采集完成，独立评分仍可能 FAIL。输出 `observations.json`、`run.json`、分案账本和 Trace 仅保存在本机。

真实模型与 Trace 演示见[演示清单](../docs/演示与交付清单.md)。可选 `semantic.py` 需另装 DeepEval、显式 judge 配置与实际回答；默认锁文件不含可选依赖，未运行不计通过。交付验证见[验证记录](../docs/reports/交付验证记录.md)。
