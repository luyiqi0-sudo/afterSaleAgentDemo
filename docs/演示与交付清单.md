# 演示工具与操作清单

招聘方已确认免交录屏。以下用于自测或现场演示，命令从仓库根目录执行；记录位于私有 `runtime/`，不交付。

## 手动聊天

pgvector 容器流程见[README](../README.md)。以下为显式 memory 本机演示，仍需要真实模型和 embedding；两个窗口分别启动，已有同端口服务时不要重复启动：

```powershell
.venv\Scripts\python -m dev.demo mock
.venv\Scripts\python -m dev.demo api --vector memory
```

第三个窗口：

```powershell
Invoke-RestMethod 'http://127.0.0.1:8080/health?mode=ready'
.venv\Scripts\python -X utf8 -m dev.demo chat "查询订单 EVAL-002 的状态、金额和物流。"
.venv\Scripts\python -X utf8 -m dev.demo chat "按2026-10-01的政策，电子发票多久开具？请引用来源。"
```

查看执行说明、工具摘要、answer_delta 与 done。澄清/确认时从 `done.data` 取 session_id，从其中的 interrupt 取 interrupt_id 和 expected_revision，传给 `chat --session ... --interrupt ... --revision ...`；消息为补充信息、“确认”或“取消”。不可复用已消费或过期中断。

`dev.demo` 自动管理本机临时凭据，`--actor other` 切换第二个合成用户。若使用本机 pgvector，先启动专属数据库，按 `.env` 的 PG_DSN 执行 `python -m knowledge.ingest --backend pgvector`，再选 `dev.demo api --vector pgvector`。

## 自动演示与 Trace 页面

下面无需外部模型，自行启动临时 Agent 和 Mock，演示订单、物流和政策：

```powershell
.venv\Scripts\python -X utf8 -m eval.runner --profile controlled --database-dir database --knowledge-path knowledge --demo --ids D01 D02 D04 --output runtime/demo-review
.venv\Scripts\python -m dev.trace_view --case runtime/demo-review/observations.json D02 --case runtime/demo-review/observations.json D04 --output runtime/demo-review/trace.html
Start-Process .\runtime\demo-review\trace.html
```

输出目录必须尚不存在，重跑换新目录。`--detail` 可展示政策原文与来源；SQL 细节需选择含对应模型/执行记录的案例。profile 改成 `real` 会调用真实模型/embedding；`--ingest-timeout 25` 调整入库批次限时，在线请求仍有独立截止。

`--demo` 包含 D01–D12：订单、物流、聚合、政策、混合建单、越权、写后未知、取消、知识缺口、读取重试、正常建单、快照篡改。D11 展示等待确认后建单，D07 展示 UNKNOWN 不重发；自动脚本在隔离场景内发送预设确认。采集成功不等于评分通过，业务失败见[评测报告](../eval/报告.md)。

## 专项工具

```powershell
.venv\Scripts\python -X utf8 -m dev.fault_probe --profile controlled --cases 429-recover 500-recover
.venv\Scripts\python -X utf8 -m dev.policy_date_probe --date 2026-09-30 --date 2026-10-01
```

故障工具独立启动临时服务，验证退避、恢复、确认和重放。日期工具需要本机演示 Mock 已运行及真实模型配置，创建隔离 API 比较参考日期，不修改运行中服务和系统日期。两者打印保存位置。

建议现场顺序：数据/健康 → 订单/物流 → 政策引用/版本 → 澄清/确认/取消 → 故障/UNKNOWN → 评分与限制。实际截图见[验证记录](reports/交付验证记录.md)。
