# 面试题需求追踪矩阵

| MVP | 实现 | 验收边界 |
|---|---|---|
| 1 混合问答与路由 | LangGraph 目标理解、逐步动作、RAG/SQL/工具路由 | 受控回归；全量真实模型稳定性未验收 |
| 2 RAG、引用、版本冲突 | 检索、日期与适用条件裁决、文档段落引用 | memory 有验证；pgvector 正向和独立语义未验收 |
| 3 Text-to-SQL | AST、显式字段、受约束 Join、只读、身份隔离 | SQL 回归；跨工具查物流不能充当 SQL Join 证据 |
| 4 数据准确性 | 实际执行结果绑定，底层分转用户元 | GOLD-11 聚合口径披露仍失败 |
| 5 三工具与建单 | 订单、物流、确认后单次发送 | 确认回归；无远端反查，UNKNOWN 人工核对 |
| 6 缺参澄清 | interrupt/Command、session/revision 校验 | 恢复、重放、旧中断拒绝回归；广泛真实措辞待验收 |
| 7 注入防御与纠错 | 输入守卫、SQL 边界、重新生成及校验 | 机制回归，不等于完整安全审计 |
| 8 重试退避与降级 | 读取 429/500 有界重试，失败后按条件提议确认建单 | 故障回归；写后未知不盲目重发 |
| 9 SSE 分段 | 执行说明、工具结果、中断和 done | 最终答案整段发送；断连不保证送达 |
| 10 API 与三容器 | `/chat`、`/health`、`/metrics`、`docker/` 三服务 | 本机 HTTP 有验证；容器与 pgvector 正向 NOT_RUN |
| 11 可观测 | 脱敏模型/SQL/政策/HTTP/耗时/token Trace 和截图 | 截图为既有实际记录；私有完整 Trace 不交付 |

技术选型为 Python 3.11+、LangGraph、SQLite、sqlglot、自建 pgvector 配置、锁定依赖、pytest 和中文 README。文件见[交付清单](交付清单.md)，实际计数见[验证记录](reports/交付验证记录.md)。

数据包含 30 篇政策（5 个旧版本）、200 订单、50 条合成对话和 36 条 Golden。合成对话不是 Agent 执行日志；公开留出不是严格盲测。

加分项中守卫、Schema 约束和可选语义适配器已有代码。图表、商品订单明细关联、Redis、摘要压缩、本地模型显存/QPS 实测未交付。招聘方已确认免交录屏。
